## Enable GitHub Pages (if not already on)

1. Open https://github.com/zhenyu-2026/uv-sticker-printers/settings/pages
2. Under **Build and deployment** → **Source**, choose **Deploy from a branch**
3. Branch: `main` · Folder: `/ (root)` → **Save**
4. Wait a few minutes, then open https://zhenyu-2026.github.io/uv-sticker-printers/
